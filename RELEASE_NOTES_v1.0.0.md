# BumpMarks v1.0.0

BumpMarks v1.0.0 is the first public release of the privacy-first baby movement
logging PWA.

## Highlights

- Fast one-tap live movement recording.
- Honest catch-up entries without invented exact timestamps.
- Daily history, notes, target display, and configurable tracking hours.
- Local descriptive analytics with User View and Doctor View.
- CSV export plus complete JSON backup and restore.
- Installable and offline-capable PWA.
- No account, ads, third-party tracking analytics, cloud data requirement, or
  AI health interpretation.
- Static production deployment so user records remain entirely browser-side.

## Important medical note

BumpMarks records and visualizes user-entered information. It does not assess
fetal wellbeing, diagnose a condition, classify a movement pattern as normal
or abnormal, or replace guidance from a qualified healthcare professional.
