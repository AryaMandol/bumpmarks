# Media assets

The lifestyle imagery in `static/images/landing-mother-window.png` and
`static/images/landing-mother-phone.png` was created specifically for the
BumpMarks project and is not sourced from a third-party stock library.

The BumpMarks project makes these two lifestyle images available under the
Creative Commons Zero v1.0 Universal dedication (CC0-1.0) for reuse without
attribution.

The BumpMarks application icons and other original interface graphics are
included with the project under the MIT License unless otherwise stated.

The application screenshot in `static/images/app-preview.png` is a capture of
the BumpMarks interface and is included for project documentation and website
presentation.
